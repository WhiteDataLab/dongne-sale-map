## 0. 30초 요약 (엘리베이터 피치)

**"우리 동네 식료품 가게의 '오늘의 떨이·세일'을 지도에서 실시간으로 보고, 주민이 직접 제보하는 하이퍼로컬 서비스."**

- 야채·정육·과일·반찬 같은 동네 소상공인의 **마감 임박 할인**을 지도 핀에 **가격까지 숫자로** 보여준다 (`🔥 2,900원~`, 1시간 내 마감은 `⏰` 강조).
- 정보를 올리는 주체는 **주민(소비자)**. 가게가 직접 안 올려도 동네 사람들이 채워 넣는 **커뮤니티 방식**.
- 올리면 **포인트 적립** → 출석·리뷰·제보·친구초대로 모은 포인트를 **기프티콘으로 교환**.
- **현재 단계**: 수요 검증 MVP를 넘어 **수익화 기능이 실제로 구현·배포**된 상태(8장). 사장님 대상 **스폰서 광고·프로 구독(토스 정기결제)·쿠폰 발행**, 운영자용 **영업 리드·전환 통계·기프티콘 제휴 정산**까지 동작한다.
  - ⚠️ 단, **실제 과금은 토스 "테스트키" 기준**으로만 검증됨 → 실매출이 돌려면 **토스 자동결제(빌링) 계약·심사**가 선행돼야 한다(8장 끝 "남은 과제"). 즉 "기능은 있고, 실 정산 스위치는 계약 후 ON".

**서비스 주소**: https://dongne-sale-map.vercel.app (모바일 웹 우선, 설치 없이 브라우저로 이용)

## 1. 누구를 위한 서비스인가 (3종 사용자)

| 사용자 | 누구 | 무엇을 하나 | 우리에게 주는 가치 |
|---|---|---|---|
| **소비자(주민)** | 동네 장보는 사람 | 세일 구경 · 세일/리뷰/휴업 제보 · 가게/메뉴 등록 · 포인트 적립·교환 | 콘텐츠 생산자 + 트래픽. 데이터의 원천 |
| **사장님(merchant)** | 동네 가게 주인 | 사업자등록증 인증 → 소유권 획득 → **전용 관리 대시보드(`/manage`)**에서 메뉴·세일·공지·배너·**쿠폰 발행**·**반응 통계**·**구독(스폰서/프로)** 관리 | **유료화 핵심 타깃** — 광고·구독·쿠폰을 실제로 결제 |
| **관리자(admin)** | 운영자(우리) | 신고 처리 · 인증 승인 · 포인트/기프티콘 운영 · 통계 | 품질·신뢰 유지 |

> 지금은 소비자가 올린 가게가 대부분이고, 사장님이 "내 가게"로 인증해 가져가는 구조(=리드 확보 → 사장님 전환 퍼널이 자연스럽게 설계돼 있음).

## 2. 핵심 사용자 여정 (한 바퀴)

```
지도 열기(동대문구 이문동 기본)
  → 검색어로 동네 이동 / '현재 위치' 버튼
  → 지도 핀에서 세일 가격 확인(마감임박은 주황 펄스)
  → 가게 누르면 상세(메뉴·세일·공지·리뷰 탭, 영업중 자동표시, 길찾기)
  → 세일 제보(사진+가격+만료시간) 또는 리뷰(별점+구매메뉴+사진/영수증 인증)
  → 포인트 적립
  → 출석체크·친구초대로 포인트 추가 적립
  → 포인트샵에서 기프티콘 교환 신청
  → (관리자 수동 발송) 등록한 연락처로 기프티콘 수령
```

소비자에게 **공유 링크**(`/s/가게id`)를 누르면 카톡 미리보기 카드(가게·세일·사진)가 떠서 바이럴 유입이 가능하다.

## 3. 전체 메뉴 지도 (지금 살아있는 화면 전부)

사이드 메뉴는 **6개 그룹**으로 정리돼 있다. (✅ = 배포 완료)

### 탐색
| 메뉴 | 설명 |
|---|---|
| ✅ 지도(홈) | 카카오맵 + 가격 핀 + 필터(업종·영업중·마감임박·세일중) + 줌아웃 시 가격 클러스터 묶음 |
| ✅ 즐겨찾기 | 저장한 가게 모아보기(위치 무관, 세일 여부 표시) |
| ✅ 동네 소식 | 최근 세일·휴업/폐업·신규가게를 모아 보여주는 피드 |

### 기여 (콘텐츠 생산 = 데이터 자산)
| 메뉴 | 설명 |
|---|---|
| ✅ 가게 등록 | 지도에서 위치를 직접 찍어 등록(주소 자동) / 카카오 장소검색으로 빠른 등록 |
| ✅ 세일 제보 | 사진 필수 + 가격 + 만료시간(1·2시간/마감까지/직접설정). 만료되면 자동 비활성 |
| ✅ 리뷰 | 별점 + 구매한 메뉴 연결 필수 + 태그 + 사진/**영수증 인증 배지** |
| ✅ 휴업/폐업 제보 | "오늘 휴업"·"폐업?"을 사진으로 제보 → 지도 핀에 경고 표시 |

### 혜택 (리워드 = 리텐션 엔진)
| 메뉴 | 설명 |
|---|---|
| ✅ 출석체크 | 하루 1회 +10P, 연속·누적 보너스 |
| ✅ 내 쿠폰 | 사장님이 발행한 쿠폰을 **받기(1인 1매)** → 매장에서 **사용하기**(사용가능/지난 쿠폰 구분) |
| ✅ 포인트샵 | 모은 포인트로 기프티콘 교환 신청 |
| ✅ 친구 초대 | 초대 링크로 가입 시 추천인·친구 **각 +50P**(악용 방어 내장) |
| ✅ 공지·이벤트 | 운영자가 올리는 공지/이벤트 배너 |

### 사장님 (merchant·admin 전용)
| 메뉴 | 설명 |
|---|---|
| ✅ **내 가게 관리(`/manage`)** | 사장님 **전용 풀페이지 대시보드**. 좁은 지도 팝업 대신 넓은 화면에서 섹션별 관리: **통계**(우리 가게 반응, 프로면 30·90일·요일별)·**메뉴**·**세일/행사**·**쿠폰 발행**·**사진**(메인+갤러리)·**가게 정보**(공지·주소·영업시간)·**구독·플랜**(가입·업그레이드·해지). 소비자용 지도 팝업은 가볍게 유지하고, 사장님에겐 "⚙️ 내 가게 관리" 링크로 안내. |

## 5. 포인트(리워드) 경제 — 수익화의 핵심 축

**적립 경로 (현재 값)**

| 행동 | 적립 |
|---|---|
| 세일 제보 | +10P (즉시) |
| 첫 리뷰 / 사진·영수증 인증 리뷰 | +10P |
| 메뉴(상품) 등록 | +5P |
| 출석체크 | +10P (+ 연속/누적 보너스) |
| 친구 초대(양쪽) | 각 +50P |

**사용 경로**: 포인트샵에서 **기프티콘 교환** → 잔액 차감 → 관리자가 등록 연락처로 수동 발송. 교환 시 **상품 원가·제휴사가 함께 기록**되어 `/admin/제휴 정산`에서 실지출·마진을 집계한다(8장).

**중요한 운영 현실 (기획 시 반드시 인지)**
- 포인트 **잔액의 진짜 출처는 적립/차감 기록의 합계**이며, 적립 후 **5년 지나면 소멸**(부채 무한 누적 방지).
- 실제 기프티콘 구매·발송은 **외부에서 수동 운영**(자동 결제·발송 연동 없음). → **기프티콘 원가 = 현재 유일한 변동비**. 교환량이 늘면 비용도 는다.
- 즉 포인트는 지금 **마케팅 비용(획득·리텐션)**이지 수익원이 아님. 수익화는 이 트래픽/데이터를 **사장님·광고주에게 파는** 방향이 정석(8장).

## 6. 우리가 쌓고 있는 데이터 자산 (마케팅·BM 재료)

- **실시간 동네 세일/가격 데이터**: 품목별 가격을 시점별로 모아 **가격 추이 그래프(최근 90일)** 제공 → 동네별·품목별 물가 인사이트로 발전 가능.
- **가게 DB**: 카카오 POI에 없는 노점·소상공인까지 자체 수집(차별 자산).
- **회원 활동 데이터**: 기여(등록/제보/리뷰/즐겨찾기) 기반 활동 점수·랭킹.
- **실시간 노출 인벤토리**: 지도 상단 **세일 광고판(가로 마퀴)**, **실시간 리뷰 스트림**, 지도 핀 — 이미 광고 슬롯이 될 화면이 존재.

> ⚠️ **위치정보(GPS 단말 좌표)는 수집·저장하지 않는다**(개인정보 최소화 원칙). '현재 위치' 버튼도 지도 이동 보조용일 뿐 좌표를 서버에 저장하지 않음. 마케팅 시 "위치 추적 안 함"은 오히려 **신뢰 포인트**로 활용 가능.

## 7. 신뢰·안전(어뷰징 방어) — 데이터 품질 = 광고 가치

광고/제휴 매출은 결국 "데이터가 깨끗하냐"에 달려 있다. 현재 방어 장치:

- **포인트 어뷰징 차단**: 세일은 항목당 하루 1회, 리뷰는 가게당 1회, 단시간 연속 작성 제한.
- **가짜 콘텐츠 차단**: 사진은 우리 서버에 올린 것만 인정 + **실제 이미지인지 파일 검증**. 신고 3건 누적 시 자동 숨김 → 사후 검토 → 악성 작성자 계정 정지.
- **추천인 악용 차단**: 보상은 SMS 인증된 연락처에만, 같은 연락처 재사용 차단.
- **시스템 보안**: 전 구간 HTTPS·보안 헤더·클릭재킹 방어, 외부 API 남용/비용 폭주 방어(분산 레이트리밋), 민감문서(사업자등록증·영수증)는 비공개 저장.
- **관리자 권한 탈취 불가**: 일반 사용자가 어떤 방법으로도 관리자/사장님 등급을 스스로 올릴 수 없음(서버가 매 요청 권한 재확인).

→ 영업 자료에 "**신뢰 가능한 동네 데이터**"로 내세울 수 있는 근거.

## 8. 수익화(BM) — 현재 구현 상태

> ⚠️ **핵심**: 아래 기능은 **코드로 구현·배포 완료**됐고, 결제는 **토스 테스트키로 전 흐름(E2E) 검증**까지 됐다. **실매출 전환에 남은 것은 외부 계약뿐** — 토스 자동결제(빌링) 심사, (기프티콘) 제휴사 계약. 즉 "기능은 ON, 실 정산 스위치는 계약 후."

| BM | 무엇을 파나 | 가격/모델 | 상태 |

### 8-2. 결제·과금이 실제로 어떻게 도는가 (기획자가 알아야 할 핵심)
- **벤더**: 토스페이먼츠 **빌링키 자동결제**(사장님이 카드 1회 등록 → 매월 자동청구). 카드번호는 **토스가 보관**, 우리 서버엔 저장 안 함.
- **흐름**: 사장님이 `/manage` 또는 가게 상세에서 플랜 선택 → 카드 등록 → **14일 무료** → 종료 후 매월 자동결제. **결제 실패 3회 누적 시 자동 해지**. 해지 시 환불 없이 남은 노출 기간까지만 유지.
- **업그레이드 악용 방지**: 스폰서로 싸게 결제 후 곧장 프로로 올려 한 주기를 싸게 쓰는 구멍을 막기 위해, **유료 상태 업그레이드 시 남은 기간 차액을 즉시 일할 청구**한다(사실상 프로 정가). 다운그레이드 후 재업그레이드 같은 변형도 차액 청구로 무력화.
- **현재 한계**: 토스 **테스트키**라 실제 돈은 빠지지 않는다. **실 빌링 계약·심사 통과 + 실키(`live_*`) 교체** 후 매출 ON. (개발자센터 가입·테스트키 발급·테스트카드 등록 E2E는 완료)

> 가장 빠른 매출 경로는 여전히 **사장님 전환(리드) → 스폰서/프로 구독**. 콘텐츠(세일·리뷰)는 주민이 채우므로, "사장님이 돈 내고 더 잘 보이게 / 관리하게"가 자연스럽다.

## 9. 아직 없는 것 (오해 방지용)

마케팅/영업 시 "(완전히) 있다"고 말하면 안 되는 것들 — **현재 미구현 또는 테스트 단계**:
- **실 결제(실매출)**: 구독·정기결제 기능은 구현됐으나 **토스 테스트키** 상태 → 실제 돈은 안 빠짐. **빌링 계약·심사 후** 실키 교체해야 매출 발생.
- **기프티콘 제휴 자동발송·자동정산**: 정산 구조/리포트는 있으나 **발송은 수동**, 실 제휴사 API 미연동(계약 후).
- 실제 **SMS 발송**(현재 개발용 목업 — 운영 발송사 연동 필요) → 전화 로그인/인증을 대규모로 쓰려면 발송사 계약 필요.
- **푸시 알림**(앱 푸시 없음, 인앱 알림함으로 대체).
- **광고주 입찰형 광고 플랫폼**: 사장님 **정액 스폰서/구독은 구현**됐으나, 외부 광고주 경매·셀프서빙 입찰·노출 단가 산정은 없음.
- 플랜 **인플레이스 다운그레이드 시 환불 없음**(다음 결제부터 낮은 금액 적용).
- 네이티브 앱(현재는 모바일 웹/PWA 지향), 즐겨찾기 폴더·신뢰 배지 고도화 등은 후보.

## 11. 신입을 위한 용어집

- **하이퍼로컬**: 아주 좁은 동네 단위(반경 수백 m~수 km)에 집중한 서비스.
- **제보**: 주민이 세일·휴업 정보를 직접 올리는 행위(우리 콘텐츠의 원천).
- **포인트(PointLog)**: 가상 리워드. 잔액은 적립/차감 기록의 합계로 계산(5년 후 소멸).
- **소셜 로그인(OAuth)**: 카카오·네이버 계정으로 가입/로그인.
- **merchant(사장님)**: 사업자등록증 인증으로 본인 가게 관리 권한을 얻은 사용자.
- **소유권(ownerId)**: 어떤 가게의 인증된 주인. 있으면 "사장님 가게"로 표기.
- **자동 숨김(soft hide)**: 신고가 일정 수(기본 3) 쌓이면 콘텐츠를 일단 가리고 나중에 검토.
- **지오코딩**: 검색어/주소를 지도 좌표로 바꾸는 것.
- **PWA**: 설치 가능한 웹앱(앱스토어 없이 홈 화면에 추가).
- **MVP**: 핵심 가설만 검증하는 최소 제품(현재 단계).
