# 메뉴/정보구조(IA) 검증 & 보완 — 동네 세일 지도

> 목적: 현재 메뉴 구성을 레퍼런스 서비스(당근마켓·오늘의집·카카오맵·네이버지도·네이버 MY플레이스·Apple)와 비교해
> **업종 무관 필수 메뉴**는 빠짐없이 채우고, **업종 특수 메뉴**는 우리 도메인(하이퍼로컬 실시간 세일 지도)에 맞게 채택/변형/제외한다.
> 단일 진실 공급원은 `PROJECT_SPEC.md`. 이 문서는 IA 설계 참고용.

## 0. 현재 구성(세션 시작 시점)
- **사이드 메뉴(12, 평면)**: 지도 · 가게 등록 · 서비스 소개 · 출석체크 · 포인트샵 · 친구 초대(+50P) · 즐겨찾기 · [마이페이지] · [관리] · 고객센터 · 이용약관 · 개인정보처리방침
- **마이페이지**: 닉네임 변경 · 적립 포인트 현황 · 연락처 수정 · 내 리뷰 · 포인트 내역 · 소셜 로그인 연결(네이버/카카오/전화) · 즐겨찾기 현황 · 회원 탈퇴/데이터 삭제
- **관리(admin)**: 대시보드 · 신고 큐 · 가게인증 · 사장님인증 · 회원정보 · 활동분석 · 기프티콘 교환 · 기프티콘 상품 · 고객센터 · 정지계정 · 소개 영상 업로드

**핵심 문제**: 평면 12개에 성격이 다른 항목(탐색/기여/리워드/내정보/지원/법적/관리)이 섞임 → 그룹핑 없음. `즐겨찾기`가 최상위 + 마이페이지에 **중복**. 법적 문서가 메인 메뉴를 차지(보통 푸터로 내림).

## 1. 레퍼런스 IA 요약 (우리 도메인 관련 부분만)

### 당근마켓 (하이퍼로컬 — 가장 유사)
- 서비스 카테고리: 중고거래 · **동네업체** · 알바 · 부동산 · 중고차 · **동네생활(커뮤니티)** · 모임 · 카페
- 공통/푸터: 회사소개 · 당근페이 · 비즈니스/광고 · 고객센터 · **이용약관 · 개인정보처리방침 · 운영정책 · 위치기반서비스 이용약관 · 청소년보호정책**
- 신뢰장치: 프로필/매너온도, 신고/차단, 내 동네 설정(인증)
- → **시사점**: 동네업체(=우리 ‘가게’), 동네생활(커뮤니티), 위치기반 약관, 운영정책, 매너/신뢰 배지.

### 네이버 MY플레이스 (장소 리뷰 — 리뷰/저장 패턴의 정석)
- 저장(장소 즐겨찾기/리스트) · **방문(타임라인=내 활동 기록)** · 리뷰 · **영수증 인증 리뷰(+포인트 50P)** · 예약/주문 · 쿠폰 · 알림
- → **시사점**: 내 활동 타임라인, **영수증/방문 인증 기반 리뷰 신뢰도**, 쿠폰(사장님 발행).

### 카카오맵 / 네이버지도 (지도 서비스 — 탐색 패턴)
- 검색(장소/주소) · **길찾기** · 즐겨찾기/저장(폴더) · 주변 카테고리 탐색(필터) · 레이어(교통/지형/거리뷰) · 대중교통 · 내 장소
- → **시사점**: **길찾기(외부 지도 딥링크)**, 저장 폴더, 주변 카테고리 필터(이미 있음). 레이어/거리뷰/대중교통은 우리에 불필요.

### 오늘의집 (콘텐츠+커머스 — 마이페이지 패턴)
- 커뮤니티/콘텐츠 · 쇼핑/스토어 · 마이페이지(주문내역 · **스크랩(폴더)** · 쿠폰 · 포인트 · 알림 · 최근 본 · 리뷰 · 고객센터 · 설정)
- → **시사점**: 마이페이지 표준 묶음(주문/쿠폰/포인트/알림/설정), 스크랩 폴더.

### Apple (대규모 IA — 그룹핑/푸터/법적 표준)
- 글로벌 nav(카테고리) + **그룹화된 푸터 메가메뉴**: 쇼핑 · 계정 · 스토어 · 비즈니스 · 교육 · **Apple의 가치관(개인정보 보호 등)** · Apple 정보 · **Legal(개인정보 처리방침 · 이용약관 · 판매 및 환불 · 법적 고지 · 사이트맵)**
- → **시사점**: 법적/회사/지원은 **푸터로 그룹핑**. **판매 및 환불 정책**(우리는 포인트→기프티콘 교환=전자상거래성), 사이트맵, 가치(개인정보 보호 강조).

## 4. 제안 IA (대분류 → 중분류 → 소분류)

### A. 사이드 메뉴(로그인 사용자 기준)
```
탐색 (Explore)
 ├─ 지도(홈)
 ├─ 즐겨찾기            ← 최상위는 여기 1곳만(마이페이지 중복 제거: 마이페이지에선 진입 링크만)
 └─ 동네 소식(P2)        ← 세일/휴업·폐업 제보/커뮤니티 통합 피드

기여 (Contribute)
 ├─ 가게 등록
 └─ 세일 제보 / 리뷰     ← 지도/가게상세 내 행동(메뉴엔 안내만)

혜택 (Rewards)
 ├─ 출석체크
 ├─ 포인트샵
 ├─ 친구 초대 (+50P)
 └─ 이벤트/공지(P1)      ← 신설

내 정보
 └─ 마이페이지 →(아래 5-A)

고객지원
 ├─ 고객센터(1:1 문의)
 ├─ 공지사항(P1)
 └─ FAQ/도움말(P2)

관리 (admin 전용)
 └─ 관리 콘솔 →(아래 5-B)
```

### B. 푸터(또는 ‘약관·정책’ 묶음) — 메인 메뉴에서 내림
```
서비스
 ├─ 서비스 소개(/about)
 └─ 회사/운영 정보(P1)      ← 운영 주체·연락처·사업자 정보(포인트 교환 운영 표기)
정책
 ├─ 이용약관
 ├─ 개인정보처리방침
 ├─ 위치기반서비스 이용약관(P0)
 ├─ 운영정책/커뮤니티 가이드(P1)
 └─ 포인트·기프티콘 교환/환불 정책(P1)
기타
 └─ 사이트맵(P2)
```

## 5. 하위 메뉴 정리

### 5-A. 마이페이지 (오늘의집/네이버 표준 묶음으로 그룹핑)
```
계정      : 프로필(닉네임/사진) · 연락처 수정 · 소셜 로그인 연결(네이버/카카오/전화)
활동      : 내 리뷰 · (내 가게/세일 제보 = ‘내 활동’ 타임라인, P2) · 즐겨찾기(진입)
포인트    : 적립 포인트 현황 · 포인트 내역 · 포인트샵(진입) · 출석체크(진입)
설정/알림 : 알림함·알림설정(P1/P2)
계정 관리 : 회원 탈퇴 및 데이터 삭제
```
> 현행 항목은 거의 다 있음 → **그룹 라벨만 붙여 4~5묶음으로** 재배치. ‘즐겨찾기 현황’은 최상위 즐겨찾기로 연결(중복 화면 제거).

### 5-B. 관리 콘솔 (역할/빈도 기준 그룹핑)
```
현황      : 대시보드 · 활동분석
심사 큐    : 신고 큐 · 가게 인증 · 사장님 인증
회원      : 회원 정보 · 정지 계정
포인트샵   : 기프티콘 상품 · 기프티콘 교환
지원/콘텐츠: 고객센터(문의 답변) · 소개 페이지 영상 업로드
```
> 현행 11개 평면 → 5묶음. 항목 추가는 없고 **그룹핑만**으로 인지부하↓.

## 6. 보완 우선순위 요약
- **P0(법적/신뢰 필수)**: 위치기반서비스 이용약관.
- **P1(완성도/분쟁대비)**: 공지/이벤트 · 인앱 알림함 · 운영정책(신고·자동숨김 기준 공개) · 회사/운영 정보 · 포인트 교환/환불 정책 · 길찾기 딥링크 · 영수증/사진 인증 리뷰 배지.
- **P2(차별화/편의)**: FAQ · 설정 · 내 활동 타임라인 · 즐겨찾기 폴더 · 동네 소식 커뮤니티 · 신뢰/활동 배지 · 사장님 쿠폰 · 사이트맵.

## 7. 즉시 정리 포인트(코드 변경 없이 IA만)
1. 법적 문서(이용약관·개인정보처리방침)를 **메인 메뉴 → 푸터/‘정책’ 묶음**으로 이동.
2. 최상위 `즐겨찾기`와 마이페이지 ‘즐겨찾기 현황’ **중복 제거**(한 화면으로 통일, 다른 곳은 링크).
3. 사이드 메뉴를 **탐색/기여/혜택/내정보/고객지원/관리** 6그룹으로 헤더 라벨링.
4. 마이페이지·관리 콘솔에 **그룹 헤더** 추가(항목 그대로, 묶음만).
