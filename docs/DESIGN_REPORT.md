## 1. 한 줄 요약

브리프의 핵심 메시지 **"지도는 그대로, 보는 느낌만 바꾼다"** 를 그대로 구현했습니다.
**기능·정보구조(IA)·API·결제 흐름은 한 줄도 바꾸지 않고**, 색·타이포·여백·질감·모션만 토스/애플 수준으로 끌어올려 **같은 트래픽에서 더 많은 전환이 일어나도록** 시각 설계를 교체했습니다.

- 범위: 전 화면(소비자 + 사장님 대시보드 + 관리자 + 공유 링크)
- 방식: **디자인 토큰 한 벌**을 단일 출처로 두고 전 컴포넌트가 이를 참조
- 결과: 디자인 시스템이 **앱 전역의 단일 출처**로 완성 (레거시 색 0에 수렴)

## 2. 디자인 원칙 — 브리프 3원칙의 실제 적용

| 브리프 원칙 | 적용 방식 | 결과 |
|---|---|---|
| **① 한눈에 (글랜서블)** | 한 카드 = 하나의 주된 행동. 가격을 800 weight 주인공으로 | 핀·세일카드·반응패널에서 "0.5초 안에 가격·다음 행동"이 읽힘 |
| **② 여백·타이포로 위계** | 얇은 보더(1px)·옅은 그림자·크고 타이트한 제목. 장식 대신 정밀함 | 화면이 "비싸 보이게" — 결제 직전 신뢰 ↑ |
| **③ 온도는 딱 한 곳 (마감임박)** | 전체는 차분한 블루·중성 회색, **세일·마감임박·예약에만** 따뜻한 주황→빨강 그라데이션 | 긴급함은 번지되 남발하지 않아 신뢰 유지 |

레퍼런스: 토스(글랜서블·큰 숫자·라이트 팔레트) + 애플(여백·타이포 위계·절제된 모션) + **우리만의 한 끗**(신선·임박의 온도).

## 4. 화면별 Before → After (핵심)

### 4-1. 가격 핀 (지도의 시그니처)
- **Before**: `이모지 + 가게명` 알약, 세일은 끝에 작은 빨강 배지 — 가격이 이름에 묻힘
- **After**: 세일 가게는 **이름을 빼고 가격이 주인공**인 흰 카드(가격 800 weight). 마감임박엔 따뜻한 `⏰ N분` 칩 + 펄스. 스폰서는 금색 카드 유지
- **왜**: 지도에서 가장 많이 기억되는 단 하나의 요소. "싸다 + 지금"을 0.5초에 전달 → 상세 진입 ↑

### 4-2. '우리 가게 반응' 패널 (구독을 만드는 화면)
- **Before**: 6개 지표를 균등한 작은 카드로 나열 — 위계·다음 행동 없음
- **After**: 큰 히어로 숫자(「이번 주 152명이 봤어요」) + 미니 스탯(갈래요 강조) + **'값 보여주고 자물쇠'** 업셀(「단골에게 알림 보내기 · 전단지 한 장 값」)
- **왜**: 사장님은 숫자를 **느낄 때** 결제. 갖고 싶게 만든 뒤 잠그는 핵심 업셀 패턴

### 4-3. 요금제 카드 (전환 표면)
- **Before**: 기능 나열 중심, 카드마다 색 제각각, 가격 본문 크기
- **After**: **결과로 프레이밍**(게시판에 올라가요 / 손님에게 먼저 연락해요 / 단골을 데이터로 관리해요) + FREE 기준선 앵커 + **라이트 '가장 인기' 추천 띠** + **프로 다크 카드로 최상위 앵커링**
- **왜**: 가격 화면 자체가 전환 표면. 라이트를 '똑똑한 선택'으로 임펄스 유도

### 4-4. 세일 카드 · 예약 CTA (거래·광고 표면)
- **Before**: 장미색 톤의 작은 버튼, 카운트다운 없음
- **After**: **딜 그라데이션 예약 버튼** + `⏰ 카운트다운` + 남은 수량. 목록은 가격을 키워(800) 결정 속도 ↑
- **왜**: 거래(GMV)·광고 과금(CPA)이 동시에 걸린 버튼 — "지금" 강조

### 4-5. 공유 OG 카드 (바이럴 표면)
- **Before**: 가게 대표사진 또는 없음 — 미리보기 밋밋, 브랜드 일관성 없음
- **After**: 카톡/SNS 공유 시 **브랜드 OG 카드 동적 생성**(가게명 + 대형 가격 딜 펄 카드). 사진 유무와 무관하게 항상 일관
- **왜**: 공유 클릭률 → 바이럴 유입의 첫인상

### 4-6. 빈 화면 / 배지 / 전역
- 빈 동네 → **'첫 제보 초대'** 카드(막다른 화면을 콘텐츠 유도로)
- 신뢰 배지 통일: 공식(블루)·프로(그라데이션)·영수증 인증(그린)·스폰서(잉크) — 의미별 색 하나씩, 한 형태(필)
- 공유 랜딩 스크롤 등장 애니메이션(애플식), 관리자·소비자 전 화면 토큰 수렴

> 컴포넌트별 상세 코드·근거는 [`DESIGN_CHANGELOG.md`](DESIGN_CHANGELOG.md) 참조.

## 5. 매출 레버 연결 (Revenue Brief 관점)

시각 품질은 전환율을 **곱하는** 변수입니다. 각 변경이 미는 레버:

| 화면 | 레버 |
|---|---|
| 가격 핀 매력 ↑ | 상세 진입(detail_open) → 사장님에게 보여줄 반응 데이터 |
| 반응 패널 + 잠금 업셀 | 무료→라이트→프로 전환율 (L1, 가장 빠른 매출 + ARPU) |
| 요금제 결과 프레이밍 | 구독 전환 (L1 직접) |
| 예약 CTA + 카운트다운 | 거래 GMV(L2) · 갈래요/길찾기 CPA(L3) |
| 공유 OG 카드 | 바이럴 유입(트래픽 품질) |

## 6. 접근성 · 성능 고려

- **모션 접근성**: 펄스·등장·hover 애니메이션은 `prefers-reduced-motion` 사용자에게 정지(전역 핀·마퀴·스트림 등 적용). *Reveal 등장 컴포넌트의 reduced-motion 대응은 후속 권장 항목.*
- **서체**: Pretendard 가변폰트 1종(100~900)을 **셀프호스팅** → 외부 CDN 의존 없이 보안 정책(CSP) 그대로 준수, 한글 렌더 일관.
- **포커스 접근성**: 키보드 포커스 링을 브랜드 컬러로 또렷하게(마우스 클릭 시 비노출).
- **숫자 정렬**: 가격은 tabular-nums로 자릿수 정렬(흔들림 없는 큰 숫자).

## 7. 효과 측정 계획

이미 깔린 행동 이벤트 로깅(M0, `StoreEvent`)으로 리뉴얼 **전/후를 같은 지표로 비교**할 수 있습니다.

| 지표 | 의미 |
|---|---|
| 핀 → 상세 진입률 (impression → detail_open) | 핀 매력의 직접 신호 |
| 상세 → 갈래요·예약 전환율 | 거래(GMV)·광고(CPA) 선행 지표 |
| 무료 → 유료(라이트/프로) 전환율 | '반응 패널 + 잠금 업셀'의 성패 |
| 라이트 → 프로 업그레이드율 | 업셀 카피·시각의 효과 |

> 정직하게: 디자인은 곱하기지 더하기가 아닙니다. 매출 스위치 자체는 **토스 실 빌링 계약**과 **동네 밀도·영업**(디자인 밖)입니다. 이 리뉴얼은 그 셋이 켜졌을 때 **같은 트래픽에서 더 높은 비율이 결제로 전환되도록** 만드는 작업입니다.

## 8. 적용 범위 & 남은 제안

**완료(배포됨)**: 디자인 토큰·폰트 → 핀·반응패널·요금제·예약 CTA → 엠프티·배지·확장통계·공유랜딩·OG카드·관리자·앱 전역 토큰 정비. *원칙(구조 불변) 끝까지 유지.*

**후속 제안 (선택, 우선순위순)**
1. **PWA**(설치·오프라인) — '앱처럼 설치' 경험, 재방문율 ↑
2. **모션 접근성 마감** — Reveal 등 reduced-motion 완전 대응
3. 잔여 비매핑 색 미세정리(다크 배경·에디터 UI 등, 한계효용 낮음)

**디자인 밖(비개발) 다음 우선순위**: 토스 실 빌링 계약 · 동네 밀도·영업.
